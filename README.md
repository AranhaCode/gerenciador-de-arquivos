📂 Gerenciador de Arquivos
Um script em Python simples e eficiente para organizar, criar e gerenciar diferentes tipos de arquivos (PDF, Imagens e Word). O projeto automatiza a criação de diretórios específicos e mantém um backup automático das operações.
✨ Funcionalidades
Criar Arquivos:
Gera arquivos de texto simulando extensões .pdf e .docx.
Processa e converte imagens para formatos .jpg (RGB) e .png usando a biblioteca Pillow.
Organização Automática: Cria pastas específicas para cada tipo de arquivo (Pdfs/, Imagens/, Words/).
Sistema de Backup: Copia automaticamente todos os novos arquivos para uma pasta Backup/.
Mover e Deletar: Permite mover arquivos entre pastas e excluir arquivos indesejados via terminal.
Visualização: Lista o conteúdo de diretórios existentes para facilitar o gerenciamento.
🚀 Como Executar
Pré-requisitos
Você precisará do Python 3 instalado e da biblioteca Pillow para o processamento de imagens.
