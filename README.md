# 📂 Gerenciador de Arquivos com Backup Automático

Um assistente de terminal em Python que permite criar diferentes tipos de arquivos (PDF, Imagens, Word) e gera backups automáticos para manter tudo organizado e seguro.

## ✨ Funcionalidades

- **Conversão de Imagens:** Transforma fotos arrastadas para o terminal em formatos `.jpg` ou `.png`.
- **Criação de Documentos:** Gera arquivos `.pdf` e `.docx` (Word) de forma rápida.
- **Backup Automático:** Cada arquivo criado é duplicado instantaneamente para uma pasta de segurança.
- **Organização por Pastas:** O sistema separa automaticamente os arquivos em pastas específicas (`Pdfs`, `Imagens`, `Words`).
- **Limpeza de Caminhos:** Remove automaticamente aspas e símbolos extras ao arrastar arquivos para o terminal (comum no Windows).
